# 🏫 अंक पत्रक (Marks Folio) एवं विद्यालय रिपोर्ट कार्ड जनरेटर

> **राज्य शिक्षा शोध एवं प्रशिक्षण परिषद् (SCERT), बिहार, पटना** के अर्धवार्षिक एवं वार्षिक मूल्यांकन दिशानिर्देशों के अनुरूप तैयार किया गया आधुनिक, स्वचालित अंक पत्रक व रिपोर्ट कार्ड जनरेटर।

## 🌟 मुख्य विशेषताएँ (Features)
- 📑 **e-Shikshakosh Excel Integration:** ई-शिक्षाकोष से डाउनलोड एक्सेल शीट से सीधे छात्र का नाम, **पिता का नाम**, **माता का नाम**, रोल नंबर, जन्म तिथि (DOB) और छात्र कोड स्वतः आयात करें।
- 👥 **माता-पिता का नाम रिपोर्ट कार्ड पर:** रिपोर्ट कार्ड पर छात्र के साथ-साथ पिता एवं माता का नाम आधिकारिक प्रारूप में स्वतः प्रदर्शित होता है।
- 📋 **केवल नाम पेस्ट करें (Smart Reasoning):** एक्सेल से केवल नाम कॉपी करके 1 सेकंड में भरें।
- 📊 **स्वचालित ग्रेडिंग (A, B, C, D, E):** कुल अंक, प्रतिशत और ग्रेड की तत्काल गणना।
- 📜 **अंक पत्रक (Marks Folio):** अर्धवार्षिक/वार्षिक मूल्यांकन का सम्पूर्ण वर्गवार शीट प्रिंट व निर्यात।
- 🖨️ **व्यक्तिगत रिपोर्ट कार्ड (PDF / Print):** 1-क्लिक में सभी या चयनित बच्चों का आधिकारिक रिपोर्ट कार्ड प्रिंट व PDF डाउनलोड।
- ⚡ **100% क्लाइंट-साइड (No Server Needed):** सभी डेटा आपके अपने ब्राउज़र में सुरक्षित रहता है, किसी बैकएंड सर्वर की आवश्यकता नहीं है।

## 🚀 GitHub Pages पर 2 मिनट में वेबसाइट लाइव करें (Free Live Website)

### चरण 1: नया GitHub Repository बनाएँ
1. [github.com/new](https://github.com/new) पर जाएँ।
2. **Repository name** में कोई भी नाम दें (जैसे: `marks-folio` या `bihar-report-card`)।
3. इसे **Public** चुनें और **"Create repository"** पर क्लिक करें।

### चरण 2: `index.html` फ़ाइल अपलोड करें
1. नए बने पेज पर **"uploading an existing file"** लिंक पर क्लिक करें।
2. इस प्रोजेक्ट की `index.html` फ़ाइल को ड्रैग करके अपलोड करें।
3. नीचे हरा **"Commit changes"** बटन दबाएँ।

### चरण 3: GitHub Pages सक्षम (Enable) करें
1. रिपॉजिटरी में ऊपर **Settings** टैब पर जाएँ।
2. बाएँ साइडबार में **Pages** पर क्लिक करें।
3. *Build and deployment* सेक्शन में:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main` (या `master`)
   - **Folder:** `/ (root)`
4. **Save** बटन दबाएँ।

### चरण 4: वेबसाइट लाइव हो गई! 🎉
लगभग 1 मिनट में GitHub आपको लाइव लिंक प्रदान कर देगा:
```
https://<your-username>.github.io/<repository-name>/
```
